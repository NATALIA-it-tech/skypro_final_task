Git

  • git init - создание нового репозитория Git
  • git clone - клонирование репозитория из удаленного хранилища
  • git add <файл> - добавление файла в отслеживание
  • git commit -m "..." - сохранение изменений в Git
  • git push - выгрузка изменений в удаленный репозиторий
  • git pull - получение изменений из удаленного репозитория
